# 🌦️ Weather App

A simple and responsive **Weather Web Application** that provides real-time weather information for any city using a public weather API.

---

## 🚀 Features
- 🔍 **City Search** – Get instant weather updates for any location.
- 🌡️ **Real-Time Data** – Displays temperature, humidity, wind speed, and weather conditions.
- 🎨 **Dynamic UI** – Background changes based on weather conditions (optional if you added it).
- 📱 **Responsive Design** – Works seamlessly on desktop and mobile.

---

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript
- **API:** [OpenWeather API](https://openweathermap.org/api) *(or your actual API source)*
